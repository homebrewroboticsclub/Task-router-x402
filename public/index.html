Fleet Enrollment

Robots call RAID POST /api/robots/enroll using the fleet enrollment secret (QR below). That is not the same as RAID→robot (X-Raid-To-Robot-Secret), which RAID uses only when pushing the teleop allowlist to the robot’s operatorRegistryUrl. See Services registration or docs/SERVICES_REGISTRATION_ROBOT.md.

After a database reset, robots do not reappear until each node enrolls again (or you add them in admin). Clipboard copy may require HTTPS or localhost; if copy fails, scan the QR or open Services registration.
